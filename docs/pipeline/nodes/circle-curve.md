title: Circle Curve
---

Generates a closed circle curve lying in the horizontal XZ plane centred at the pipeline origin.

## Ports

| Port | Direction | Type | Required |
|---|---|---|---|
| origin | Input | Vec3 | No |
| curve | Output | Curve | — |

## Parameters

| Parameter | Description |
|---|---|
| Radius | Circle radius in blocks (1.0–64.0) |
