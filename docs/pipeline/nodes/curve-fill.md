title: Curve Fill
---

Fills a solid tube of blocks along a curve by stamping spheres of the given radius at each curve point.

## Ports

| Port | Direction | Type | Required |
|---|---|---|---|
| curve | Input | Curve | Yes |
| blocks | Output | Block map | — |

## Parameters

| Parameter | Description |
|---|---|
| Radius | Tube radius in blocks (0.5–10.0) |
| Palette | Block palette used to fill the tube |
