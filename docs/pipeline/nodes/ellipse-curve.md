title: Ellipse Curve
---

Generates a closed ellipse curve lying in the horizontal XZ plane centred at the pipeline origin.

## Ports

| Port | Direction | Type | Required |
|---|---|---|---|
| origin | Input | Vec3 | No |
| curve | Output | Curve | — |

## Parameters

| Parameter | Description |
|---|---|
| Radius X | Ellipse radius along the X axis (1.0–64.0) |
| Radius Z | Ellipse radius along the Z axis (1.0–64.0) |
