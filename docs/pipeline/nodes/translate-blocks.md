title: Translate Blocks
---

Shifts all blocks in a block map by a fixed integer offset along each axis.

## Ports

| Port | Direction | Type | Required |
|---|---|---|---|
| blocks | Input | Block map | Yes |
| blocks | Output | Block map | — |

## Parameters

| Parameter | Description |
|---|---|
| Offset X | Block offset along the X axis (-128–128) |
| Offset Y | Block offset along the Y axis (-128–128) |
| Offset Z | Block offset along the Z axis (-128–128) |
