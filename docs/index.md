Dimensium is a powerful building and sculpting mod for Minecraft 1.7.10.

## Features

- **Selection tools** — box, freehand, lasso, and magic selection; [selection operations](/tools/selecting/operations) to filter, distort, fill, replace, and more
- **Creating tools** — fill, shape, path, sculpt, stamp, and more
- **Manipulating tools** — move, extrude, elevation, smooth, and more
- **Painting tools** — paint, gradient, and noise-based painting
- **Masks** — filter which blocks any tool may affect
- **Blueprint system** — save, browse, and load structures
- **Undo/redo history** — unlimited steps, persisted across sessions
- **Autoshade** — shade selections with directional lighting and a block palette
- **Palette** — organise frequently used blocks into categories
- **[Pipeline editor](/pipeline)** — node-based procedural generation
