Creating tools place new blocks into the world within or around a selection.

| Tool | Description |
|---|---|
| [Fill](/tools/creating/fill) | Flood-fills a selection with blocks |
| [Freehand](/tools/creating/freehand) | Paint blocks freely with a brush |
| [Modelling](/tools/creating/modelling) | Clay-like push/pull modelling |
| [Path](/tools/creating/path) | Extrude a shape along a drawn path |
| [Rock](/tools/creating/rock) | Generate natural rock formations |
| [Sculpt](/tools/creating/sculpt) | Sculpt terrain with soft brushes |
| [Shape](/tools/creating/shape) | Place geometric primitives |
| [Stamp](/tools/creating/stamp) | Stamp a clipboard blueprint |
