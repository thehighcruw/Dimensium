title: Painting Tools
---

Painting tools replace block types within a selection without changing geometry.

| Tool | Description |
|---|---|
| [Gradient](/tools/painting/gradient) | Apply a block gradient across the selection |
| [Noise](/tools/painting/noise) | Paint with noise-driven block distribution |
| [Painter](/tools/painting/painter) | Brush-based block replacement |
