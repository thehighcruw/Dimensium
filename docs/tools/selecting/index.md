Selecting tools define the region that other tools operate on.

| Tool | Description |
|---|---|
| [Box](/tools/selecting/box) | Drag an axis-aligned box selection |
| [Freehand](/tools/selecting/freehand) | Draw a freehand selection volume |
| [Lasso](/tools/selecting/lasso) | Lasso-select by drawing a closed shape |
| [Magic](/tools/selecting/magic) | Select contiguous matching blocks |

## Operations

Once you have a selection, the **Selection** and **Operations** windows provide tools to modify it or the blocks within it.

See [Selection Operations](/tools/selecting/operations) for a full reference.
