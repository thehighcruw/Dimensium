title: Manipulating Tools
---

Manipulating tools transform an existing selection in place.

| Tool | Description |
|---|---|
| [Distort](/tools/manipulating/distort) | Randomly displace blocks |
| [Elevation](/tools/manipulating/elevation) | Raise or lower terrain |
| [Extrude](/tools/manipulating/extrude) | Push faces outward |
| [Melt](/tools/manipulating/melt) | Erode edges of a selection |
| [Modify](/tools/manipulating/modify) | Create translated copies, revolve, or twist a selection |
| [Move](/tools/manipulating/move) | Translate a selection |
| [Roughen](/tools/manipulating/roughen) | Add surface irregularity |
| [Shatter](/tools/manipulating/shatter) | Break a selection into fragments |
| [Slope](/tools/manipulating/slope) | Reshape terrain along a defined slope |
| [Smooth](/tools/manipulating/smooth) | Smooth jagged surfaces |
| [Weld](/tools/manipulating/weld) | Fill gaps between selections |
