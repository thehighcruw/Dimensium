The Ruler tool measures distances and angles by placing points in the world. In Default mode, each new point extends a polyline and distances between consecutive points are displayed. In Circle mode, three points define a circle and its radius is shown.

## Controls

| Input | Action |
|---|---|
| RMB | Place a measurement point at the cursor block |

## Parameters

| Parameter | Description |
|---|---|
| Mode | `Default` — polyline distance measurement; `Circle` — three-point circle with radius display |

## Tips

- In Default mode, the cumulative path length is shown alongside each segment distance.
- In Circle mode, place three non-collinear points to compute the circumscribed circle radius.
- Points persist until you switch tools or clear them manually.
