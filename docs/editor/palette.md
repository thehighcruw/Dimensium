The palette organises your frequently used blocks into named categories. Most painting and creating tools draw their block from the palette's **active block**. Keeping your palette stocked saves time compared to opening the block picker on every stroke.

## Palette Window

Open the **Palette** window from the editor overlay. The window shows:

- **Active block** — the block currently used by tools. Click it to open the block picker and change it.
- **Recent** — up to 16 blocks used recently, shown as a grid.
- **Categories** — user-defined groups of blocks, each collapsible.

## Active Block

The active block is shown at the top of the Palette window. Tools that place or paint blocks use it automatically. Click the block icon to replace it with a different block from the picker.

## Categories

You can create any number of named categories to organise your blocks:

- **Add category** — creates a new empty category.
- **Add block** — click the `+` button inside a category to pick a block and add it.
- **Remove block** — right-click a block icon in a category and choose **Remove**.
- **Replace block** — right-click a block icon and choose **Replace** to swap it for another.
- **Set as active** — right-click a block icon and choose **Set Active** to make it the active block.
- **Reorder** — drag block icons within a category to reorder them.
- **Delete category** — right-click the category header and choose **Delete Category**.

## Palette Editor

The **Palette Editor** window (accessible from the editor overlay) provides a more compact view for bulk editing — adding, removing, and reordering categories and blocks without the preview grid.

## Tips

- The Recent section auto-populates as you use blocks; no manual management needed.
- Organise categories by project (e.g. "Stone types", "Wood") to switch themes quickly.
