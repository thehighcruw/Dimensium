Layout presets save and restore the positions and sizes of all editor windows. Use them to switch between different workspace arrangements — for example, a compact layout for laptops and a wide layout for large monitors.

## Managing Presets

Open **Layout Presets** from the menu bar (or from the overlay). The window lists all saved presets. The active preset is marked with `*`.

| Action | How |
|---|---|
| **Save current layout** | Type a name in the input field at the bottom and click **Save** |
| **Load a preset** | Click **Load** next to a preset name |
| **Rename a preset** | Double-click the preset name to edit it inline; press Enter to confirm |
| **Delete a preset** | Click **Del** next to a preset name |

## What Is Saved

A preset captures the position, size, and open/closed state of every editor window (Palette, Clipboard, History, Selection, Operations, Tool Options, etc.). Window contents — palette blocks, history entries — are not part of the preset.

## Tips

- Save a preset before experimenting with window arrangement so you can restore it easily.
- Preset names are arbitrary; use descriptive names like "wide", "compact", or "stream".
